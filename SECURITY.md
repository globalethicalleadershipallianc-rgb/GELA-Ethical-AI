# 🔒 Security Policy

## Reporting a Vulnerability

We take security seriously. If you discover a security vulnerability, please:

1. **Do not** open a public issue
2. Send an email to: **globalethicalleadershipallianc@gmail.com**
3. Include the following details:
   - Description of the vulnerability
   - Steps to reproduce (if possible)
   - Potential impact
   - Any suggested fix (optional)

We will respond within **48 hours** and keep you updated on the progress.

## Supported Versions

| Version | Supported          |
|---------|--------------------|
| 1.0.x   | ✅ (current)       |
| < 1.0   | ❌ not yet released|

## Scope

This policy applies to the GELA core repository (`GELA-Ethical-AI`) and its official documentation.

## Preferred Language

You may report in **English** or **Bengali**.
