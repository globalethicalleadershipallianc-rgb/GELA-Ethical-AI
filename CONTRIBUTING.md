# 🤝 Contributing to GELA

We welcome contributions! Please follow these steps:

## How to Contribute

1. **Fork the repository**
2. **Create a feature branch**: `git checkout -b feature/your-feature`
3. **Commit your changes**: `git commit -m "Add your feature"`
4. **Push to the branch**: `git push origin feature/your-feature`
5. **Open a Pull Request**

## Guidelines

- Write clear, descriptive commit messages
- Follow the existing code style
- Add tests for new features
- Update documentation as needed
- Be respectful and constructive in discussions

## Code of Conduct

Please be respectful, constructive, and focus on the project's mission: **Justice, Unity, Humanity**.

All contributors are expected to uphold our Code of Conduct (see CODE_OF_CONDUCT.md).

## Questions?

Feel free to open an issue or start a discussion. We're here to help!
