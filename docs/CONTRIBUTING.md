# 🤝 Contributing to GELA

We welcome contributions from everyone who shares our vision of **ethical, open-source AI**.

## How to Contribute

1. **Fork the repository**  
2. **Create a feature branch**:  
   `git checkout -b feature/your-feature-name`  
3. **Make your changes**  
   - Follow the existing code style (Black formatter, type hints, docstrings)  
   - Ensure the ethics guardrail is not broken  
4. **Commit your changes**:  
   `git commit -m "Add: description of your feature"`  
5. **Push to your fork**:  
   `git push origin feature/your-feature-name`  
6. **Open a Pull Request**  

## Code of Conduct

We follow a [Code of Conduct](./CODE_OF_CONDUCT.md). Please read it before contributing.

## Style Guidelines

- Use **Black** for Python formatting (`black .`)
- Add **type hints** to all functions
- Write **docstrings** for all public functions and classes
- Use the project's `utils.logger` for logging

## Questions?

Open an issue or contact the founder.

**Thank you for helping build ethical AI.** ⚖️
