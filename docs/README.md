# 🌍 GELA – সম্পূর্ণ ডকুমেন্টেশন

স্বাগতম। এটি **GELA** (Global Ethical Leadership Alliance) -এর অফিসিয়াল ডকুমেন্টেশন রিপোজিটরি।

GELA একটি বৈশ্বিক নৈতিক নেতৃত্ব জোট যা কৃত্রিম বুদ্ধিমত্তা, মানবাধিকার এবং যুদ্ধ প্রতিরোধের মাধ্যমে মানবতার সেবা করে।

## 📖 কীভাবে এই ডকুমেন্টেশন ব্যবহার করবেন

### নতুনদের জন্য
1. **[ভিশন স্টেটমেন্ট](01_Vision_Statement/)** দিয়ে শুরু করুন — GELA কী এবং কেন এটি তৈরি হয়েছে তা বুঝতে
2. **[হোয়াইটপেপার](02_White_Paper/)** পড়ুন — প্রযুক্তিগত বিস্তারিত জানতে
3. **[চার্টার](03_Charter/)** অধ্যয়ন করুন — সংগঠনের কাঠামো ও শাসন বুঝতে

### ডেভেলপারদের জন্য
- **[HUMANE ব্লুপ্রিন্ট](05_HUMANE_Blueprint/)** — টেকনিক্যাল আর্কিটেকচার বুঝতে
- **[API রেফারেন্স](10_API_Docs/)** — ইন্টিগ্রেশন তথ্য পেতে
- **[স্মার্ট কন্ট্রাক্ট ABI](10_API_Docs/Smart_Contract_ABI.json)** — ব্লকচেইন ইন্টারঅ্যাকশনের জন্য

### সদস্যদের জন্য
- **[সদস্যপদ গাইডলাইন](04_Membership/)** — যোগদান ও সুবিধা জানতে
- **[AGES প্রশিক্ষণ](06_AGES_Training/)** — নৈতিক নেতৃত্ব প্রশিক্ষণ অ্যাক্সেস করতে

### তহবিল সংগ্রহকারীদের জন্য
- **[ফান্ডিং প্রপোজাল টেমপ্লেট](08_Funding/)** — অর্থ আবেদনের জন্য
- **[পাইলট প্রোজেক্ট প্ল্যান](07_Pilot_Plan/)** — প্রকল্প পরিকল্পনা দেখতে
